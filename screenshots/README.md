# Captures d’écran

Les captures doivent être faites depuis l’application en fonctionnement (et non à partir d’une maquette) afin de documenter l’interface réelle. Prévoir : accueil, Markdown, édition Markdown, code, PDF, image, CSV, thème clair et thème sombre.

Le build Windows et l’automatisation des captures nécessitent une fenêtre WebView2 interactive. Les captures seront ajoutées ici lors d’un build de validation Windows. Pour produire rapidement une capture locale, lancez `npm run tauri:dev` puis utilisez l’outil Capture d’écran de Windows.
