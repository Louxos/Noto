# Journal des modifications

Les changements notables sont consignés ici. Le format suit une version simplifiée de Keep a Changelog.

## [Non publié] — 2026-10-06

### Ajouté
- Groupes de fichiers locaux avec création, couleurs, renommage, ajout/retrait de documents et suppression sûre sans toucher aux originaux.
- Menus Fichier, Édition, Affichage et Aide, palette de commandes filtrable et fenêtre récapitulative des raccourcis.
- Raccourcis pour naviguer entre onglets, éditer, chercher, créer/classer dans des groupes et ouvrir les paramètres.
- Réglages d’accent coloré, de barre latérale compacte, de barre d’outils compacte et d’ordre/visibilité des commandes.
- Feuille de route produit priorisée dans `ROADMAP.md`.

## [0.1.0] — 2026-10-05

### Ajouté
- Première version de Noto : application Tauri 2 avec interface React/Vite.
- Viewers Markdown, code/texte, HTML isolé, PDF, image et CSV.
- Édition texte simple, aperçu Markdown en direct, sauvegarde locale, recherche et raccourcis.
- Onglets, glisser-déposer, fichiers récents, thèmes et paramètres locaux.
- Configuration d’installateur Windows, associations de formats, tests et workflows GitHub Actions.
