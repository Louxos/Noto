# Un aperçu avec Noto

Un espace clair pour lire **sans distraction**, puis modifier quand une petite correction suffit.

## Une lecture confortable

- Titres et paragraphes bien hiérarchisés
- Listes, citations et liens
- Tableaux et tâches Markdown

> Noto garde vos documents sur votre appareil.

| Format | Expérience |
| --- | --- |
| Markdown | Rendu et édition en direct |
| Code | Coloration syntaxique et numéros de lignes |
| PDF | Navigation et zoom |
